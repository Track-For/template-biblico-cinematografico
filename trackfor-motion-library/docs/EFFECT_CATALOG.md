## Regras para implementação de receitas

1. Comece com uma versão acessível sem animação; aprimore progressivamente.
2. Monte isoladamente, com cleanup e fallbacks (especialmente se WebGL).
3. Para shaders: forneça vertex, fragment, uniforms (`uTime`, `uProgress`, `uTexture`, `uResolution`), redimensionamento e dispose.
4. Use ScrollTrigger com `scrub` somente para transform/opacity/shader uniforms quando possível.
5. Corrija diferenças desktop/mobile em `gsap.matchMedia()`.

## Presets de direção de arte

- **Editorial premium:** texto por linhas + parallax leve + clip reveal + transições lentas.
- **Arquitetura / imóveis:** hero em imagens, gallery reveal, scroll storytelling e hotspots.
- **Luxo / moda:** máscaras, tipografia cinética com moderação, carousel editorial e hover image.
- **Tech / startup:** progressão visual, timelines, reveal de métricas, morphings sutis.
- **Experimental Awwwards:** WebGL displacement, scene transitions, partículas; fallback simples obrigatório.

## Prioridades de performance

- Sempre GPU friendly `transform` e `opacity`; evite animar `top`, `left`, dimensões/layout continuamente.
- `will-change` apenas quando necessário, nunca globalmente.
- Use `ResizeObserver` para atualizar valores que dependem de dimensões; `ScrollTrigger.refresh()` depois de grandes alterações.
- Fontes e imagens devem ter tamanhos conhecidos para evitar layout shift.
- Em projetos de conversão, não esconda CTA nem informações importantes esperando scroll.
